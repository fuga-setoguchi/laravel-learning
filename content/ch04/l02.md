## 概念

**ルートモデル結合**は、ルートのパラメータの値からモデルを取り出して、コントローラーに渡す仕組みです。

```php
Route::get('/posts/{post}', [PostController::class, 'show']);

// PostController
public function show(Post $post)
{
    return view('posts.show', ['post' => $post]);
}
```

公式ドキュメントによると、型にモデルを書いた引数の名前が、ルートのパラメータの名前と一致していれば、Laravel が自動でモデルを取り出します（暗黙の結合）。`/posts/42` なら、id が 42 の `Post` が `$post` に入ります。見つからなければ、自動で 404 のレスポンスが返ります。

id 以外の列で探すこともできます。

```php
Route::get('/posts/{post:slug}', [PostController::class, 'show']);
```

いつも同じ列で探すなら、モデルに `#[RouteKey('slug')]` 属性を付けます。

## なぜ必要か

`Post::find($id)` を自分で書くと、見つからないときの扱いを毎回書く必要があります。書き忘れると、null のまま処理が進み、エラー（500）になります。ルートモデル結合なら、取り出しと 404 が一律に行われ、コントローラーは「見つかったモデル」だけを扱えます。

## どこに書くか

| やりたいこと | 書き方 |
| --- | --- |
| id でモデルを取り出す | ルートを `{post}` にし、引数を `Post $post` にする |
| 別の列で探す | `{post:slug}` か、モデルの `#[RouteKey]` 属性 |
| 見つからないときの処理を変える | ルートに `->missing(...)` |
| ソフトデリートしたモデルも取り出す | ルートに `->withTrashed()` |
| 親子のモデルの組み合わせを確かめる | ルートやグループに `->scopeBindings()` |
| 取り出し方そのものを変える | `AppServiceProvider` の `boot` で `Route::bind(...)`（明示的な結合） |

暗黙の結合で足りる場面がほとんどです。`Route::bind()` で取り出し方を書く明示的な結合は、名前の列で探すなど、決まった形に収まらないときに使います。書いた場合は、見つからないときに `firstOrFail()` などで 404 になるようにします（公式ドキュメントの例も `firstOrFail()` を使っています）。

`/users/{user}/posts/{post}` のように2つのモデルを受け取るとき、ふつうは2つが別々に探されます。`->scopeBindings()` を付けると、`post` は `user` のリレーションを通して探されます。公式ドキュメントによると、`{post:slug}` のようにキーを指定した場合は、自動でこの絞り込みが行われます。

## 良い例と悪い例

悪い例: id を受け取り、自分で探す。

```php
public function show(int $id)
{
    $post = Post::find($id);

    return view('posts.show', ['post' => $post]);
}
```

なぜ悪いか: 見つからないと null がビューに渡り、エラーになります。

良い例: ルートモデル結合で受け取る（「概念」のコードを参照）。

## AIが書きがちな誤り

- ルートモデル結合を使わず、コントローラーで `find($id)` してから null を確かめる
- ルートを `{id}` にしたまま、引数を `Post $post` にする。名前が一致しないので結合されず、DB から取り出していない空の `Post` が渡る（公式ドキュメントの記載ではなく、Laravel 本体の実装による動き）
- 親子のモデルを受け取るルートで、組み合わせを確かめない

ルートのパラメータとコントローラーの引数を見たら、「名前がそろっているか」「親子の組み合わせを確かめる必要はないか」を確かめましょう。

## まとめ

- ルートのパラメータの名前と、モデルを型に書いた引数の名前をそろえると、モデルが自動で取り出される
- 見つからなければ自動で 404。変えたいときは `->missing()`
- id 以外の列は `{post:slug}` や `#[RouteKey]` で指定する
- 親子のモデルの組み合わせは `->scopeBindings()` で確かめる
