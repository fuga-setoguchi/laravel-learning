## 概念

**HTTP 例外**は、404（見つからない）や 403（許可されていない）のような、HTTP のエラーのレスポンスにするための例外です。公式ドキュメントによると、アプリのどこからでも、`abort` で HTTP 例外を投げられます。

```php
abort(404);

abort_if($post->is_locked, 403);        // true のとき
abort_unless($post->isPublished(), 404); // false のとき
```

投げられた例外は、例外の処理がそのステータスコードのレスポンスに変えます。1件のモデルを取り出すなら、`findOrFail` やルートモデル結合（第4章）を使えば、見つからないときに `ModelNotFoundException` が投げられ、自動で 404 になります。

## なぜ必要か

見つからないデータの画面を、ふつうの `view` で返すと、ステータスコードは 200（成功）になります。ブラウザや検索エンジン、API を呼ぶ側、監視の仕組みは、ステータスコードで成功・失敗を判断するので、失敗に気づけません（一般的な考え方）。

逆に、利用者の入力が原因の問題を 500 にすると、サーバーの障害と区別できなくなります。ステータスコードは、「何が起きたか」を呼ぶ側に伝える大事な情報です。

なお、他人のデータへのアクセスを 403 ではなく 404 で拒否して、データがあること自体を隠す方法は、第11章で扱いました。どのステータスコードを返すかは、呼ぶ側に何を伝えたいかで選びます。

## どこに書くか

| 場面 | 書き方 |
| --- | --- |
| 1件のモデルが見つからない | `findOrFail`、ルートモデル結合 |
| 条件を満たさないときに止める | `abort_if`・`abort_unless` |
| 認可で拒否する | Policy と `Gate::authorize` など（第8章） |
| エラーページのデザイン | `resources/views/errors/404.blade.php` など |

公式ドキュメントによると、`resources/views/errors/404.blade.php` を置くと、アプリで起きた 404 のエラーすべてに使われます。`abort` で投げた例外は `$exception` という変数でビューに渡されます。既定のページを書き換えたいときは、`php artisan vendor:publish --tag=laravel-errors` でひな形を出せます。

`4xx.blade.php`・`5xx.blade.php` を置くと、個別のページがないステータスコードに使われます。ただし、401・402・403・404・419・429・500・503 には使われないので、これらは個別のページを置きます。

`abort` は HTTP のための仕組みなので、コマンドやジョブからも呼ばれる Action の中では、自作の例外を投げ、HTTP のレスポンスへの変換はコントローラーや例外の `render` に任せます（一般的な考え方）。

## 良い例と悪い例

悪い例: 見つからない画面を 200 で返す。

```php
$post = Post::find($id);
if ($post === null) {
    return view('posts.not-found');
}
```

なぜ悪いか: ステータスコードが 200 なので、呼ぶ側は成功したと判断します。

良い例: 見つからなければ 404 にする。

```php
public function show(Post $post)
{
    return view('posts.show', compact('post'));
}
```

## AIが書きがちな誤り

- 見つからないときに `null` やふつうの画面を返し、200 のままにする
- 何が起きても `abort(500)` にする
- コマンドやジョブからも呼ばれるクラスで `abort` を使う
- `4xx.blade.php` を置けば、404 のページも変わると考える

エラーの処理を見たら、「呼ぶ側に、正しいステータスコードが伝わるか」を確かめましょう。

## まとめ

- `abort`・`abort_if`・`abort_unless` で HTTP 例外を投げる
- 1件のモデルは `findOrFail` やルートモデル結合で、見つからなければ 404 にする
- エラーページは `resources/views/errors/404.blade.php` などに置く
- HTTP 以外からも呼ばれるクラスでは、`abort` ではなく自作の例外を投げる
