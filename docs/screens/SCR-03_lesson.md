# SCR-03 レッスン

作成日: 2026-11-16
ステータス: 確定（2026-11-16）
対応要件: FR-07, FR-08
関連: [05_review-logic](../05_review-logic.md) 6章（CompleteLesson）

## 1. 概要

| 項目 | 内容 |
| --- | --- |
| Controller | `LessonController`（`show` / `read` / `recall` / `complete` / `completed`） |
| ビュー | `resources/views/lessons/{pre-question,read,recall,completed}.blade.php` |
| 目的 | 事前の問い → 本文 → その場で思い出す → 完了 を、段階ごとの画面で進める |

| 段階 | メソッド・パス | 名前 |
| --- | --- | --- |
| 1 事前の問い | `GET /lessons/{lesson}` | `lessons.show` |
| 2 本文 | `GET /lessons/{lesson}/read` | `lessons.read` |
| 3 その場で思い出す | `GET /lessons/{lesson}/recall` | `lessons.recall` |
| 完了処理 | `POST /lessons/{lesson}/complete` | `lessons.complete` |
| 4 完了 | `GET /lessons/{lesson}/completed` | `lessons.completed` |

- 引退したレッスン・存在しないidは、すべての段階で404
- 段階1を飛ばすことはできない（事前の問いの回答は必須）。段階2以降のURLは、進行状況をサーバーに保存しないため直接アクセスできるが、段階2は `answer` がない場合に段階1へ戻す

全段階に共通して、画面上部に次を表示する。

```
第3章 サービスコンテナと依存性の注入 / 3-2
なぜコントローラーでnewせずに注入するのか
[1 事前の問い] > [2 本文] > [3 思い出す] > [4 完了]   ← 現在の段階を強調（aria-current="step"）
```

## 2. 段階1 事前の問い

```
┌──────────────────────────────────────────────┐
│ （共通の見出し）                                 │
│ 読む前に、予想で答えてください（記録はされません）   │
│                                              │
│ コントローラーの中で new PaymentService() と     │
│ 書くと、テストで困ることはどれか。                  │
│  ( ) 1. テストで偽物の PaymentService に…        │
│  ( ) 2. 処理が遅くなる                           │
│  ( ) 3. 文法エラーになる                          │
│ [答えて本文へ]                                  │
└──────────────────────────────────────────────┘
```

| No | 項目 | 内容 |
| --- | --- | --- |
| 1 | 問題文 | `pre_question.prompt`（Markdown） |
| 2 | 選択肢 | ラジオボタン（`name="answer"`、値は `key`、`required`）。表示順は ChoiceShuffler（シードはレッスンid）、番号は表示順 |
| 3 | 答えて本文へ | **GET**フォームで `lessons.read` へ送信（`?answer=b`）。答えずに本文へ進む手段は置かない。選択肢を選ぶまでは淡く表示し、選ぶと通常の色にする（`public/css/app.css` の `:has()`。JavaScriptは使わない） |

## 3. 段階2 本文

```
┌──────────────────────────────────────────────┐
│ （共通の見出し）                                 │
│ ┌ 事前の問いの結果 ───────────────────────┐     │
│ │ 正解 / 不正解（あなたの答え: … 正解: …）   │     │
│ │ 解説: …                                │     │
│ └────────────────────────────────────────┘     │
│ 対象: Laravel 13.x  出典: Service Container ↗  │
│                                              │
│ （本文 Markdown、コードはハイライト）              │
│                                              │
│ [本文を閉じて思い出す]                            │
└──────────────────────────────────────────────┘
```

| No | 項目 | 内容 |
| --- | --- | --- |
| 1 | 事前の問いの結果 | 正誤・あなたの答え・正解・解説を表示する。`answer` がない、またはその問いの `key` でない場合は `lessons.show` へリダイレクトする |
| 2 | 対象バージョン | `laravel_version` |
| 3 | 出典 | 出典（`kind = source`）を順に表示。新しいタブで開く（`target="_blank" rel="noopener noreferrer"`） |
| 3b | 補足資料 | 補足資料（`kind = reference`）があれば、出典の下に「参考（経緯・背景）」として順に表示する。開き方は出典と同じ |
| 4 | 本文 | `Markdown::toHtml(body)` |
| 5 | 本文を閉じて思い出す | `lessons.recall` へのリンク |

## 4. 段階3 その場で思い出す

```
┌──────────────────────────────────────────────┐
│ （共通の見出し）                                 │
│ 本文を見ずに、頭の中で答えてから開いてください        │
│ （ここでの結果は記録されません）                     │
│                                              │
│ Q1. コンストラクタで依存を受け取ると…               │
│  ▶ 答えを見る                                   │
│ Q2. …                                         │
│  ▶ 答えを見る                                   │
│                                              │
│ [完了して復習に登録する]                          │
└──────────────────────────────────────────────┘
```

| No | 項目 | 内容 |
| --- | --- | --- |
| 1 | 想起カード | レッスンの有効な想起カード（`type = recall`）を `position` 順に表示。答えは `<details><summary>答えを見る</summary>…</details>` |
| 2 | 完了して復習に登録する | `lessons.complete` へPOST（`@csrf`） |
| 3 | 本文に戻る | ブラウザの「戻る」で戻る（リンクは置かない。`answer` を引き継げないため）。表示は「本文に戻る場合はブラウザの戻るを使ってください」 |
| 4 | 出典・本文 | 表示しない |

- 選択式・AIコードレビュー問題はこの画面に出さない（初回は翌日の復習で解く）

## 5. 完了処理（POST）

1. `CompleteLesson` を実行する
2. `lessons.completed` へリダイレクトし、新たに登録した件数をフラッシュで渡す
3. 再送信（二重送信・戻るボタン）しても、CompleteLessonは冪等なので状態は変わらない（登録件数0として表示される）

## 6. 段階4 完了

```
┌──────────────────────────────────────────────┐
│ （共通の見出し）                                 │
│ レッスンを完了しました                            │
│ 5 問を復習に登録しました。最初の復習は明日です。     │
│ [ホームへ]   次のレッスン: 3-3 …                 │
└──────────────────────────────────────────────┘
```

| No | 項目 | 内容 |
| --- | --- | --- |
| 1 | 登録件数 | フラッシュの件数が1以上: 「N 問を復習に登録しました。最初の復習は明日です。」。0（再受講）: 「このレッスンの問題はすでに復習に登録されています。」。フラッシュがない（再読み込み・直接アクセス）: 件数の文は表示しない |
| 2 | ホームへ | `home` へのリンク |
| 3 | 次のレッスン | SCR-01 と同じ規則の次のレッスン。なければ表示しない |

- 未完了のレッスンでこのURLに直接アクセスした場合は、`lessons.show` へリダイレクトする
