# LAYOUT 共通レイアウト

作成日: 2026-11-27
ステータス: 確定（2026-11-27）
対象: すべての画面（SCR-01〜04）

## 1. 概要

| 項目 | 内容 |
| --- | --- |
| ビュー | `resources/views/layouts/app.blade.php` |
| メニュー | `App\View\Components\Sidebar`（`resources/views/components/sidebar.blade.php`） |
| アイコン | `App\View\Components\Icon`（`resources/views/components/icon.blade.php`） |
| 目的 | 画面の左にメニューを置く管理画面風の構成にし、機能を足すときはメニューに1項目足すだけで済むようにする |

## 2. レイアウト

### 2.1 幅が広い画面（768px 以上）

```
┌────────────────┬─────────────────────────────────────┐
│ Laravel学習     │ ※フラッシュメッセージ（ある場合のみ）     │
│                │                                     │
│ [⌂] ホーム      │  各画面の内容（@yield('content')）      │
│ [▯] カリキュラム │                                     │
│ [↻] 復習        │                                     │
│                │                                     │
│ （画面の高さに  │                                     │
│   固定）        │                                     │
└────────────────┴─────────────────────────────────────┘
  メニュー（幅 14rem）  本文（最大 60rem）
```

- メニューは画面の左に固定し、本文をスクロールしても動かない
- 本文は読みやすさのため最大幅を持つ（Pico の既定の幅は、メニューの分だけ狭くなるため上書きする）

### 2.2 幅が狭い画面（768px 未満）

```
┌─────────────────────────────────────┐
│ Laravel学習                          │
│ [⌂] ホーム  [▯] カリキュラム  [↻] 復習  │
├─────────────────────────────────────┤
│  各画面の内容                         │
└─────────────────────────────────────┘
```

- メニューは画面の上に横並びで表示する（JavaScript を使わないため、開閉するメニューにはしない）

## 3. 項目定義

| No | 項目 | 内容 |
| --- | --- | --- |
| 1 | アプリ名 | 「Laravel学習」。`home` へのリンク |
| 2 | メニュー | `<nav aria-label="メインメニュー">` の中に、メニュー項目を上から順に並べる |
| 3 | メニュー項目 | アイコンとメニュー名。今いる画面の項目に `aria-current="page"` を付け、色を変える |
| 4 | フラッシュメッセージ・エラー | 従来どおり本文の先頭に表示する |

### 3.1 メニュー項目

| 順 | メニュー名 | アイコン | リンク先 | 選択中にする画面（ルート名） |
| --- | --- | --- | --- | --- |
| 1 | ホーム | `home` | `home` | `home` |
| 2 | カリキュラム | `book` | `curriculum` | `curriculum`、`lessons.*`（レッスンはカリキュラムから開くため） |
| 3 | 復習 | `review` | `review.show` | `review.*` |

## 4. メニューの持ち方

- メニュー項目は `Sidebar::items()` に、`MenuItem`（メニュー名・ルート名・アイコン名・選択中にするルート名の一覧）の配列として持つ。ビューには項目を直接書かない
- 機能を足すときは、`items()` の末尾に1行足す。新しいアイコンが必要なら、`Icon` の一覧にも1つ足す
- アイコンはインラインの SVG で表示する。外部のアイコンフォントや画像は読み込まない（[方式設計書](../02_architecture.md) 6章「外部ファイル」）
  - 形は自作の簡単な線画とし、`Icon::PATHS`（アイコン名 => SVG の中身）に持つ
  - 一覧にないアイコン名を指定したら、例外にする（書き間違いにすぐ気づくため）
  - アイコンは飾りなので `aria-hidden="true"` を付け、メニュー名を必ず並べて表示する
- 見た目は `public/css/app.css` に書く（JavaScript は使わない）
