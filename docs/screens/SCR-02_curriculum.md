## 1. 概要

| 項目 | 内容 |
| --- | --- |
| パス | `GET /curriculum`（`curriculum`） |
| Controller | `CurriculumController`（`__invoke`） |
| ビュー | `resources/views/curriculum.blade.php` |
| 目的 | 全体の見通しと、任意のレッスンの受講 |

## 3. 項目定義

| No | 項目 | 内容 |
| --- | --- | --- |
| 1 | 章 | 引退していない `chapters` を番号順に表示。「第N章 タイトル」 |
| 2 | 章の進捗 | 完了した有効なレッスン数 / 有効なレッスン数（%）。有効なレッスンが0件の章は「準備中」 |
| 3 | レッスン | 章内の有効なレッスンを `position` 順に表示。「章-順番 タイトル」。`lessons.show` へのリンク |
| 4 | 完了状態 | 完了済みは「✓」と「完了」（スクリーンリーダー用の文字を併記）、未完了は「・」 |
| 5 | 未登録の問題 | 完了済みのレッスンで、`review_states` がない有効な問題がある場合に件数を表示する（教材に問題が追加された場合）。レッスンを再受講して完了すると登録される |

- 引退したレッスンは表示しない

## 4. 動作

| 契機 | 動作 |
| --- | --- |
| 表示 | 状態は変更しない |
| レッスン名を押下 | `lessons.show` へ遷移（完了済み・未完了にかかわらず受講できる） |

## 5. 補足

- 章・レッスン・完了状態・未登録の問題数は、Eager Loading と `withCount` で取得し、N+1にしない（クエリ数をテストで確認する）
