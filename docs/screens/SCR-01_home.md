# SCR-01 ホーム

作成日: 2026-11-16
ステータス: 確定（2026-11-16）
対応要件: FR-05

## 1. 概要

| 項目 | 内容 |
| --- | --- |
| パス | `GET /`（`home`） |
| Controller | `HomeController`（`__invoke`） |
| ビュー | `resources/views/home.blade.php` |
| 目的 | 毎日の入口。「今日の復習 → 新しいレッスン」の順に案内する |

## 2. レイアウト

```
┌──────────────────────────────────────────────┐
│ Laravel学習      [ホーム] [カリキュラム]          │  ← 共通ヘッダー（layouts/app）
├──────────────────────────────────────────────┤
│ ※フラッシュメッセージ（ある場合のみ）              │
│                                              │
│ ① 今日の復習                                   │
│   残り 12 問（うち再出題 2 問）                  │
│   [復習を始める]                                │
│                                              │
│ ② 次のレッスン                                  │
│   第3章 サービスコンテナと依存性の注入              │
│   3-2 なぜコントローラーでnewせずに注入するのか      │
│   [レッスンを始める]                             │
│                                              │
│ 全体の進捗  8 / 52 レッスン完了（15%）            │
│ 復習に登録済みの問題 40 問                       │
└──────────────────────────────────────────────┘
```

## 3. 項目定義

| No | 項目 | 内容 |
| --- | --- | --- |
| 1 | 今日の復習の残り件数 | `ReviewQueue` の残り件数（[05_review-logic](../05_review-logic.md) 4.3）。再出題が0件なら「うち再出題」は表示しない |
| 2 | 復習を始める | `review.show` へのリンク。残りが0件のときは表示せず、「今日の復習は完了しました」と表示する |
| 3 | 次のレッスン | 有効なレッスンのうち、未完了で、章番号・順番が最も前のもの。章番号・章タイトル・レッスン番号・タイトルを表示する |
| 4 | レッスンを始める | `lessons.show` へのリンク |
| 5 | 次のレッスンがない場合 | 有効なレッスンが0件: 「教材がありません。`php artisan lessons:import` で取り込んでください」。すべて完了: 「すべてのレッスンを完了しました」 |
| 6 | 全体の進捗 | 完了した有効なレッスン数 / 有効なレッスン数（%は小数点以下切り捨て） |
| 7 | 復習に登録済みの問題 | `review_states` がある有効な問題の件数 |

## 4. 動作

| 契機 | 動作 |
| --- | --- |
| 表示 | 上記をDBから集計して表示する。状態は変更しない |
| 今日の復習が残っている | 「次のレッスン」の見出しに「復習を終えてから進めましょう」と添える（リンクは無効にしない） |

## 5. 補足

- クエリ数は件数によらず一定にする（レッスンの一覧をループで数えない。`withCount` / 集計クエリを使う）
